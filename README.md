# Site premium de librairie

## Modifier rapidement le contenu

Le fichier le plus important est `content.js`.

Tu peux y changer :
- le nom de la librairie ;
- l'adresse ;
- le téléphone ;
- l'email ;
- les horaires ;
- les liens Instagram / Facebook ;
- les catégories ;
- les livres, prix, auteurs et descriptions.

Le design reste séparé dans `styles.css`.
Les interactions sont dans `app.js`.

## Lancer le site

Ouvre simplement `index.html` dans un navigateur.

Pour Vercel :
1. importe ce dossier dans un dépôt GitHub, ou glisse le projet dans ton environnement habituel ;
2. aucun build n'est nécessaire ;
3. le site est entièrement statique.

## Structure

- `index.html` : structure de la page
- `styles.css` : design, responsive, ombres, animations
- `content.js` : contenu à modifier facilement
- `app.js` : interactions, recherche, fenêtres, carrousel
- `vercel.json` : configuration simple Vercel

## Important

Les livres et le nom "Maison des Pages" sont des exemples de démonstration.
Remplace-les par les vraies informations de la librairie dans `content.js`.
